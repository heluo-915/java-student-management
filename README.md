# Java 学生管理系统

## 项目简介

这是一个使用 Java 21 开发的控制台学生管理练习项目，主要用于巩固 Java 面向对象编程、封装、构造方法、集合及实例方法等基础知识。

## 已实现功能

- 添加学生信息
- 查看全部学生
- 根据姓名查找学生
- 根据姓名删除学生（删除一个匹配项）

## 技术栈

- Java 21
- ArrayList
- IntelliJ IDEA

## 项目结构

- `Student.java`：学生实体类，包含姓名、年龄、成绩等属性。
- `StudentManager.java`：学生管理类，负责添加、查询、删除和遍历学生。
- `TestStudent.java`：程序入口，用于测试各项功能。

## 运行方式

1. 使用 IntelliJ IDEA 打开项目。
2. 配置 JDK 21。
3. 运行 `TestStudent.java` 中的 `main()` 方法。

## 项目说明

本项目是 Java 基础学习阶段的练习作品，目前使用内存集合保存数据，程序结束后数据不会持久化。

后续将根据学习进度逐步完善异常处理、交互功能和其他能力。
